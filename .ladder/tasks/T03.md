# T03: Self-contained offline test runner
Tier: sonnet · Reviewer: opus · Deps: T01

## Brief
Goal: one command runs every OFFLINE test and fails loudly; no test depends on files outside the repo.
Contract: PLAN.md §Architecture (Mac node 22, DH node 18; tests must pass on both).
Files: `tests/run-all.sh`, `tests/fixtures/*`, `build/test-foopee.mjs`, `build/test-citylights.mjs`, `build/test-free-title.mjs`, `build/test-imports.mjs` (edit tests only as needed to make them self-contained).
Steps:
1. Find out which tests touch the network or absolute paths (`build/test-foopee.mjs` reads `/tmp/lvtest/fp0.html`; `build/test-citylights.mjs` references network/paths). Try to recover the original fixtures: `ssh hermes 'ls -la /tmp/lvtest'`, and `ssh hermes 'ssh dh-backup "ls -la /tmp/lvtest ~/whattodo72.com/test/build/*.html 2>&1"'`. If a fixture is gone, regenerate a MINIMAL real one from the live source (e.g. fetch the foopee/City Lights page through `ssh hermes 'ssh dh-backup "curl -s ..."'`) trimmed to a handful of listings, and note in the test header that it was re-captured and when. Never hand-write fake listings.
2. Make each test resolve fixtures relative to `import.meta.url` (`tests/fixtures/`), no `/tmp` paths.
3. `tests/run-all.sh`: (a) `node --check` every `build/*.mjs`; (b) `bash -n` every `*.sh`; (c) run each offline test file, print `PASS/FAIL <file> (<n> checks)`, summary line, exit non-zero if any fails; (d) run `node build/test-imports.mjs build`. Exclude network tests (list them in a comment at the top of the script with the reason). Runnable from any cwd.
4. Run it on node 22 locally AND on DH node 18: `tar c . | ssh hermes 'ssh dh-backup "rm -rf /tmp/t03 && mkdir /tmp/t03 && tar x -C /tmp/t03 && cd /tmp/t03 && bash tests/run-all.sh"'`; clean `/tmp/t03` after.
Acceptance: `bash tests/run-all.sh` exits 0 on node 22 and on DH node 18.
Constraints: tests must exercise the REAL shipped parsers, never copies; if a test cannot be made offline, exclude it and say why in the result; no secrets; do not change non-test source behavior.
