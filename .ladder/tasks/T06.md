# T06: Source report sidecar and an honest final message
Tier: sonnet · Reviewer: opus · Deps: T05

## Brief
Goal: the build can say, per source, how many rows it registered and kept, and which sources failed or were skipped; the closing line stops claiming success when a module was skipped.
Contract: PLAN.md C2, C3; validator CLI in `build/validate-feed.mjs` (already built, T07).
Files: `build/fetch.mjs` (and `build/dc-fetch.mjs` only if trivial), `tests/source-report.test.mjs`, extend `tests/replay/run.sh` to also check the report (copy the report into the `--out` dir and verify it).
Rules:
- Every row passed to `register()` must carry a stable lower-case `row.source` ("dothebay" for rows from `add()` / citywide / venues, plus the existing names normalized: funcheap, citylights, omnivore, foopee, decentered, luma, sfstation, sfcb, workshopsf, clayroom, scrap, espn). Today some rows have none; the `source` key is still deleted before `events.json` is written (output byte-identical to the golden).
- Count `registered` at registration and `kept` for rows surviving to the written feed; write `build/.source-report.json` per C2 just before the feed is written. `failed` = a source whose fetches all failed per the `fetchFailureReport` ledger or that threw; `skipped` = module unavailable (the existing `omnivore: unavailable ... skipped` path); `reason` holds the one-line message.
- The last console line: `every source fetch succeeded` ONLY when none failed and none skipped; otherwise `sources: N ok, M skipped (names), K failed (names)`.
- A source that registers 0 rows with no failure is `ok` with `kept: 0` (sfcb/clayroom/scrap legitimately return 0 on many days).
Acceptance: `bash tests/replay/run.sh` exits 0 (identical to golden); in the replay output `.source-report.json` exists, `sum(kept) == totals.kept == events.length` (192 in the golden), omnivore is `skipped`, and `node build/validate-feed.mjs --events <out>/events.json --report <out>/.source-report.json --floors build/source-floors.json` exits 0; `bash tests/run-all.sh` exits 0.
Constraints: no change to `events.json` bytes; no new dependencies; keep the diff to fetch.mjs small; do not touch http.mjs semantics.
