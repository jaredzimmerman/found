# T07: Feed validator
Tier: sonnet · Reviewer: opus · Deps: T03

## Brief
Goal: a validator that would have blocked the 2026-10-07 bad feed (12 events with string `categories`, a `null` venue), plus per-source floors and a delta guard.
Contract: PLAN.md C3, C4, C5 (history format) and C2 (report format).
Files: `build/validate-feed.mjs`, `build/source-floors.json`, `tests/validate.test.mjs`, `tests/fixtures/feed-good.json` (60 real events trimmed from `curl -s https://whattodo72.com/events.json`, keeping the real envelope keys `generatedAt, days, counts, neighborhoods`), register the test in `tests/run-all.sh` (T03 owns that file; add one line, do not restructure).
Rules:
- Export `validateFeed(feed, ctx)` (pure, no I/O) and a CLI wrapper; node 18 + node 22 compatible, no dependencies.
- Taxonomy: derive the allowed category list from `build/fetch.mjs` (the `MAP`/`KEYWORDS` values and fallbacks such as "Community", "Sports & Fitness") by exporting or re-reading the single source of truth; do NOT hard-code a second copy that can drift. If extraction needs a small export in fetch.mjs, make it side-effect free (fetch.mjs runs `main()` on import: check how it is guarded before importing it!).
- `source-floors.json` seed: `{"dothebay":{"min":60,"required":true}}` plus optional (required:false) entries `funcheap` 8, `foopee` 5, `luma` 2, `sfstation` 3. Source-name matching is case-insensitive; a floors entry with no matching report entry is a warning, not a fatal.
- Delta guard per C4, reading `logs/history.jsonl` (C5). Tests must cover: <3 published runs -> uses `ctx.liveTotal`; `--accept-delta`; one-shot `.accept-delta` file consumed; >160% is only a warning.
- Tests (>= 25 checks): good feed passes; the string-categories regression, null-where-string, duplicate ids, `source` key present, bad date, `days` wrong length, missing today, empty categories, unknown category, floor breach required vs optional, delta fatal and warning cases all behave as C4 says.
Acceptance: `node tests/validate.test.mjs` exits 0 and prints the check count; `bash tests/run-all.sh` still exits 0.
Constraints: report problems with the event id and field; never mutate the feed; no network in tests; do not edit build/fetch.mjs behavior.
