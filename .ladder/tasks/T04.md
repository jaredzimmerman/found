# T04: Replay harness, frozen time, golden output
Tier: opus · Reviewer: fable · Deps: T03

## Brief
Goal: make `build/fetch.mjs` (and `dc-fetch.mjs`) runnable OFFLINE and DETERMINISTICALLY against recorded HTTP responses, so every later change can be proved output-identical against a golden file.
Contract: PLAN.md C10.
Files: `tests/replay/record.sh`, `tests/replay/record-preload.mjs`, `tests/replay/replay-preload.mjs`, `tests/replay/run.sh`, `tests/replay/compare.mjs`, `tests/replay/README.md`, `tests/golden/events.golden.json` (+ `dc-events.golden.json` if feasible). Source files in `build/` may be touched ONLY to add a tiny injectable seam for the sync `curl` HEAD calls (`fetchSync` in `build/fetch.mjs` and `build/shared.mjs`) if a preload cannot cover them; any such seam must be a no-op in production.
Steps:
1. Map every external I/O path: `grep -n "fetch(\|execFileSync\|spawnSync\|http\.\|https\.\|new Date\|Date.now\|Math.random\|setTimeout" build/*.mjs`. `sucuri.mjs` and `citylights-parse.mjs` may use their own HTTP; cover them too.
2. Record preload (`--import`, runs ON DreamHost so recordings match prod egress): wrap `globalThis.fetch` and the curl HEAD helper; key = sha1(METHOD + " " + url); store `{status,statusText,headers,bodyBase64}` under `fixtures/` plus `meta.json` (`{frozenNow: ISO, recordedAt, nodeVersion, count}`). Use `module.syncBuiltinESMExports()` after patching `node:child_process` so named imports see the patch.
3. Replay preload: serve from fixtures, THROW a clear error on a miss (never fall through to the network), freeze `Date` (no-arg `new Date()` and `Date.now()` return `frozenNow`; constructors with args untouched) and make `setTimeout` pacing instant (env `REPLAY_FAST=1`, default on).
4. Record once on DH: copy `build/` to a temp dir there, run the recording, pull `fixtures/` back to `fixtures/` here (gitignored), tar it to `hermes:/root/backups/whattodo72-fixtures-20261007.tgz`. The recording run must NOT touch the live site (`cd` into the temp copy; never run `build-site.sh`).
5. `tests/replay/run.sh`: copies `build/` (source only) to a temp dir, runs `node --import tests/replay/replay-preload.mjs fetch.mjs` there, normalizes (drop `generatedAt`), compares with `tests/golden/events.golden.json` through `compare.mjs`, which prints added/removed/changed event ids and per-field changes (not a raw diff) and exits 1 on any difference. `--update-golden` is the only way to rewrite the golden and must be explicit.
6. Golden = replay output of the BASELINE code (this tree at the time of T04; build/ is still byte-identical to tag `prod-baseline-20261007`: verify with `git diff prod-baseline-20261007 -- build/` being empty or only your seam).
Acceptance (all must hold): `bash tests/replay/run.sh` exits 0 twice in a row and the two normalized outputs are byte-identical (`cmp`); a negative test proves a deliberate change (edit one category in a temp copy of fetch.mjs) makes `run.sh` exit 1; the recorded fixture count and total size are printed in the Result.
Constraints: no live-site writes; never print the DreamHost password; reach DH only via `ssh hermes` then `ssh dh-backup`; node 18 compatible (`--import` exists in 18.19); if some path cannot be replayed, say so explicitly in the Result and in README rather than silently skipping it.
